# Discord Bot Privacy Policy
This privacy policy explains how this Discord bot handles data. Because this bot is self-hosted, the person running the bot is responsible for the infrastructure and hosting environment where the data is processed.

## Data Collection & Usage
This bot processes basic server information and user data necessary for its features and moderation functions. This includes information provided directly through the DiscordAPI, such as server IDs, channel IDs, user IDs, usernames and a bit more.


To perform moderation and logging duties, the bot also processes message content. This includes scanning active messages for automated moderation triggers and tracking deleted messages to display in server audit logs and the Discord bot. Please note that automod is not implemented in the bot at all right now. 

*The bot does not collect, process, or store private personal identifiers such as IP addresses or real-world locations.*


## Data Storage and Retention
Any data handled by the bot is stored locally on the host machine or database configured by the server administrator running the bot. The creator of this bot software has no access to your data, your server messages, or the logs generated by your specific running instance. Data retention periods are determined entirely by the system administrator hosting the bot.


## Data Sharing
No data is shared with third parties by the bot software. All data transmission stays strictly within the self-hosted environment and the official Discord API.

User Rights
Users who wish to have their data removed should contact the administrator of the specific Discord server hosting the bot instance, as the bot creator does not control or store any server data.
